# MCP Manager v0.5.0

v0.5 是一次完整的界面重构：把重复的看板页和按智能体聚合的配置页合并成唯一的「服务目录 + 详情检查器」工作台，调试能力收进检查器里的调试抽屉，并换用新的暖白 / 石墨 / 鼠尾草绿视觉系统。

Version 0.5 is a full interface redesign built around a single server catalog + inspector workbench, with debugging moved into a contextual drawer inside the inspector.

## Highlights

- 服务目录按服务聚合：搜索，按传输类型、状态和范围筛选，并直接看到每个服务被哪些智能体使用。
- 检查器展示运行状态、CPU / 内存、服务源、配置路径和逐智能体开关；远程服务通过短 HTTP 探测展示可达性，本地 stdio 服务展示 PID、运行时长和资源占用。
- 一次添加，写入多个智能体：从远程 URL、npm 包、本地命令或本地路径添加服务，按目标格式写入 JSON、YAML 或 TOML，支持全局与项目范围。
- Registry 发现：在应用内搜索 add-mcp registry 和官方 MCP registry，元数据可预填安装参数。
- 从代码仓库直接安装：优先使用 Release 预编译包（下载 + sha256 校验 + 解包，不执行脚本），没有预编译包时回退到源码安装；Python 项目使用独立虚拟环境。
- 调试抽屉：启动受管 stdio 进程，实时查看 stdout / stderr、CPU 与内存，并通过 JSON-RPC 输入框发送消息。
- 默认中文，可在侧边栏切换英文，选择会被记住；共支持 28 个智能体目标。

## Download

从本页下方的 Release assets 下载对应平台安装包：

- macOS：下载 `.dmg` 安装包（Apple Silicon 与 Intel 各一份）。
- Windows：下载 `.msi` 或 `-setup.exe` 安装包。
- Linux：下载 `.AppImage`（免安装）或 `.deb` / `.rpm` 安装包。

如果对应平台的安装包尚未附加，可以从源码构建：

```bash
pnpm install
pnpm tauri build
```

## Notes

- 未安装的智能体也可以预先写入配置。
- MCP Manager 会写入本机智能体配置，调试时可以启动本地 stdio 命令，也可以从代码仓库下载安装服务。只运行你信任的 MCP Server，提交项目级配置前先检查生成内容。
- 安装包尚未代码签名时，macOS 和 Windows 可能弹出额外的安全提示。
- 如果 macOS 提示应用已损坏，请参阅 [macOS 安装排错](../macos-install-troubleshooting.md)。
